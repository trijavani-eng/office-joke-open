One line of office comedy, written by `main.py` to `/output/entry.txt`:

> I hit reply-all to say thanks, and now 400 people are thanking me for thanking them.

Built for the make.fun bounty "Make the AI Judge Laugh: the Office Joke Open" (https://make.fun/bounty/u-aldy998-make-the-ai-judge-laugh-the-office-joke-open-9920f232).

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, standard library only) writes a constant string, so two runs write byte-identical output. No randomness, no clock, no network.
